# Preparar el entorno

Para ejecutar Circe, sigue la [guía vigente de instalación](https://github.com/javiarmesto/circe-compras-copilot-studio/blob/main/docs/01-setup-vscode.md) en el repositorio operativo.

Para consultar la charla, descarga el PowerPoint de `slides/` o abre `dist/index.html` en un navegador. Las guías HTML en `docs/` también funcionan localmente; la ejecución de la demo necesita tu entorno de Copilot Studio.
