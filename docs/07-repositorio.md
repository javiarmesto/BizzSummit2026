# Trabajar con estos materiales

`BizzSummit2026` contiene la presentación y sus guías. `circe-compras-copilot-studio` contiene el código operativo.

```powershell
git clone https://github.com/javiarmesto/BizzSummit2026.git
cd BizzSummit2026
code .
```

Abre `dist/index.html` para la presentación o los HTML de `docs/` para las guías. Para ejecutar la demo clona el repositorio operativo en otra carpeta.

Para proponer cambios, crea una rama y una pull request. No incluyas configuración de tenant, credenciales ni capturas con información privada.

La web alojada en ChatGPT tiene una publicación independiente: un commit en GitHub no actualiza automáticamente ese alojamiento ni modifica su audiencia.
