# Circe dentro de la marca del usuario

Dirección: Open Engineering Notebook. Papel #F8F7F3, tinta #111827, estructura navy #25235F, ejecución cyan #25C8D8 y criterio humano magenta #C02B84. Retícula fina, tipografía sobria y anotaciones breves.

El nuevo símbolo propuesto de Circe combina una C abierta con la sugerencia de un cáliz y un hilo cyan. La marca magenta señala intervención humana. Es una propuesta creada para esta sesión, no una recuperación acreditada de un logo antiguo.

Los assets generados están en `assets/`. El fondo puede repetirse en todas las diapositivas; el emblema actúa como identidad del proyecto. No se usa la marca del evento como sistema visual principal. No se presenta a Circe como un producto oficial de Microsoft.

La web y el PowerPoint comparten contenido. Se puede adaptar después al marco del evento conservando los assets separados. La web funciona sin CDN, fuentes externas ni conexión a una IA y no simula una conversación con Copilot Studio.
